# Contratos de API

Antes de implementar un endpoint, registrar aquí su contrato OpenAPI o una decisión equivalente. Cada operación debe indicar: recurso, método, entrada, salida, rol/cliente autorizado, códigos HTTP, errores y ejemplo seguro.

Contratos a elaborar en el primer sprint:

- `device-service`: dispositivos y estado.
- `telemetry-service`: publicación técnica y consulta de lecturas.
- `alert-ticket-service`: umbrales, alertas y tickets no críticos.
- `report-service`: resúmenes autorizados.
